# Strokera Architecture Document

**Version:** 0.1.0  
**Status:** Planning / Alpha  
**Last Updated:** 2026-09-20

---

## 1. Overview

Strokera is an **Open Painting Runtime** that enables machines to paint with the same structural richness as human artists. The core insight is that strokes should be treated as first-class mathematical objects, not just pixels in a generated image.

### 1.1 Core Philosophy

```
Current AI Art:      Image → Generated Image (instant)
Strokera Vision:     Image → Stroke Graph → Progressive Canvas → Painting
```

Strokera produces:
- **Editable** stroke sequences
- **Progressive** rendering (watch the painting form)
- **Professional** brush physics
- **Open** data formats

### 1.2 Design Goals

1. **No New Model Training Required** - v0.1 combines existing algorithms
2. **Open Standard** - `.stroke` format is free to use
3. **Professional Output** - Brush physics, layering, surface interaction
4. **Extensible** - Modular architecture for algorithm swapping

### 2.1 Module Responsibilities

| Module | Input | Output | Key Functions |
|--------|-------|--------|---------------|
| `ImageAnalyzer` | Image | `AnalysisResult` | Edge detection, segmentation, depth |
| `PaintingPlanner` | `AnalysisResult` | `PaintingPlan` | Layer structure, region grouping |
| `StrokePlanner` | `PaintingPlan` | `StrokeGraph` | Stroke prediction (PaintTransformer) |
| `StrokeOptimizer` | `StrokeGraph` | `StrokeGraph` | Parameter optimization (diffvg) |
| `BrushEngine` | `StrokeGraph` | Canvas | Physics-based rendering |
| `StrokeFile` | `StrokeGraph` | `.stroke` | Persistence, exchange |

## 3. Core Data Structures

### 3.1 Stroke

```python
@dataclass
class Stroke:
    id: str                          # Unique identifier
    type: StrokeType                 # PREDICTED | OPTIMIZED | INTERACTIVE
    layer_id: str                   # Layer assignment
    brush_id: str                   # Brush reference
    
    # Path (Bezier control points)
    path: List[Tuple[float, float]]  # [(x, y), ...]
    
    # Properties
    width: float                     # Base width in pixels
    width_profile: NDArray           # Width variation along path
    color: Tuple[float, float, float]  # RGB [0, 1]
    opacity: float                   # [0, 1]
    angle: float                    # Rotation in radians
    
    # Physics
    pressure_curve: NDArray          # Pressure modulation
    
    render_order: int               # Painting sequence
```

**Key Insight**: Strokes are mathematical objects that can be:
- Generated by neural networks
- Optimized by gradient descent
- Edited by humans
- Serialized to files

### 3.2 StrokeGraph

```python
class StrokeGraph:
    id: str
    strokes: Dict[str, Stroke]      # All strokes by ID
    stroke_order: List[str]         # Rendering order
    
    # Layer management
    layers: Dict[str, List[str]]     # layer_id → stroke_ids
    
    # Grouping (objects, regions)
    groups: Dict[str, Set[str]]      # group_id → stroke_ids
    
    # Dependencies
    dependencies: Dict[str, Set[str]] # stroke_id → must_render_before
```

### 3.3 Canvas

```python
class Canvas:
    width: int
    height: int
    background: Tuple[int, int, int]  # RGB
    
    layers: Dict[str, Layer]
    active_layer_id: str
    surface: Surface                 # Paper/canvas texture
    
    # Rendering
    def render() -> NDArray[np.uint8]  # Final image
```

### 3.4 Brush

```python
class Brush:
    id: str
    name: str
    type: BrushType                  # OIL, WATERCOLOR, INK, etc.
    
    # Shape
    shape_profile: str               # round, flat, fan
    base_width: float
    taper_enabled: bool
    
    # Physics
    physics: BrushPhysics            # Pressure response, scattering, etc.
    
    # Material-specific
    impasto: float                   # 3D texture (oil)
    granulation: float               # Texture (watercolor)
    bleed: float                     # Spreading (marker)
```

```

    │
```

## 5. Optimization Pipeline

### 5.1 Differentiable Rendering (diffvg)

```
StrokeGraph
    │
    ▼
┌─────────────────────────────────────────┐
│    DifferentiableRenderer (diffvg)      │
├─────────────────────────────────────────┤
│                                         │
│  For each stroke parameter:              │
│    s = (P, W, C, α)                     │
│                                         │
│    Where:                               │
│      P = path (control points)          │
│      W = width                          │
│      C = color                          │
│      α = opacity                        │
│                                         │
│    Render(s) → Image                    │
│                                         │
│    Loss = ||Image - Target||²           │
│                                         │
│    ∂Loss/∂s = backprop(Image)           │
│                                         │
│    s = s - lr × ∂Loss/∂s               │
│                                         │
└─────────────────────────────────────────┘
    │
    ▼
Optimized StrokeGraph
```

### 5.2 Optimization Config

```python
@dataclass
class OptimizationConfig:
    learning_rate: float = 0.01
    iterations: int = 100
    
    optimize_position: bool = True
    optimize_width: bool = True
    optimize_color: bool = True
    optimize_path: bool = False  # Expensive
    
    pixel_loss_weight: float = 1.0
    perceptual_loss_weight: float = 0.1
    smoothness_loss_weight: float = 0.01
    
    early_stopping_patience: int = 10
```

## 6. .stroke File Format

### 6.1 Format Specification

`.stroke` files are ZIP archives containing structured JSON:

```
painting.stroke
├── manifest.json      # Version, metadata
├── graph.json         # StrokeGraph serialization
├── canvas.json        # Canvas state
├── strokes.json       # Strokes (for quick access)
├── layers.json        # Layer structure
└── textures/          # Optional texture images
```

### 6.2 manifest.json

```json
{
  "version": "1.0",
  "graph_id": "graph_a1b2c3d4",
  "canvas_width": 1024,
  "canvas_height": 1024,
  "include_pixels": true,
  "created": "2026-09-20T12:00:00Z",
  "tool": "strokera v0.1.0"
}
```

### 6.3 graph.json

```json
{
  "id": "graph_a1b2c3d4",
  "strokes": {
    "stroke_001": {
      "id": "stroke_001",
      "type": "predicted",
      "layer_id": "background",
      "brush_id": "watercolor",
      "path": [[100, 200], [150, 220], [200, 250]],
      "width": 12.5,
      "color": [0.23, 0.18, 0.12],
      "opacity": 0.85,
      "render_order": 1
    }
  },
  "stroke_order": ["stroke_001", "stroke_002", ...],
  "layers": {
    "background": ["stroke_001", "stroke_002"],
    "foreground": ["stroke_050", ...]
  },
  "groups": {},
  "dependencies": {}
}
```

## 7. Brush System

### 7.1 Brush Types

| Type | Characteristics | Presets |
|------|-----------------|---------|
| Oil | Impasto, glaze, slow drying | `oil_round`, `oil_flat` |
| Watercolor | Granulation, wet spread, transparent | `watercolor` |
| Ink | Bleed, scattering | `ink_brush` |
| Marker | Multiply blend, bleed | `marker` |
| Pencil | Scattering, bristle gaps | `pencil` |
| Charcoal | Soft edges, high scatter | `charcoal` |

### 7.2 Brush Physics

```python
@dataclass
class BrushPhysics:
    # Pressure response
    pressure_min: float = 0.1
    pressure_max: float = 1.0
    pressure_curve: float = 1.0  # Exponential curve
    
    # Width response
    width_pressure_scale: float = 1.0
    width_tilt_scale: float = 0.0
    
    # Texture
    texture_intensity: float = 0.0
    texture_scale: float = 1.0
    
    # Bleeding
    bleed_amount: float = 0.0
    bleed_variance: float = 0.0
    
    # Blending
    blend_mode: str = "normal"
    layer_buildup: float = 0.1
```

## 10. API Reference

### Basic Usage

```python
from strokera import (
    ImageAnalyzer,
    PaintingPlanner,
    StrokePlanner,
    Canvas,
    Brush,
    BrushEngine,
    StrokeFile,
)

# 1. Analyze image
analyzer = ImageAnalyzer()
analysis = analyzer.analyze("photo.jpg", mode=ImageAnalyzer.AnalysisMode.FULL)

# 2. Plan painting
planner = PaintingPlanner()
plan = planner.plan(analysis, strategy="auto", target_strokes=5000)

# 3. Generate strokes
stroke_planner = StrokePlanner()
graph = stroke_planner.plan(plan, brush=Brush.create_preset("oil_round"))

# 4. Render to canvas
canvas = Canvas(1024, 1024)
brush_engine = BrushEngine((1024, 1024))
brush_engine.render_stroke_graph(graph, brush, canvas.get_active_layer().pixels)

# 5. Save
canvas.render().save("result.png")
StrokeFile().save("painting.stroke", graph, canvas)
```
